# Sherlock Holmes Primer — Interactive

An interactive companion to Arthur Conan Doyle's Sherlock Holmes canon — the four novels and all fifty-six short stories — in eleven browsable chapters, with original illustrations in homage to Sidney Paget's Strand engraving style.

**Live site:** https://profjoleong.github.io/sherlock-holmes-primer-interactive/

Also available on Muse (the link used in the "More Than Chat: Muse Builds It For You" video description): https://muse.ai/s/sherlock-holmes-primer-interactive-xjd6vxwxjxg4qxmxt/-eq3pLqLEsnaogVQ-HG4MhVRiRIoKmFb6ivMOzqeFQI

## What it does

- **Canon explorer** — searchable list of all 4 novels and 56 stories in their collections, each with record number, date, and magazine
- **Two chronologies** — the in-universe timeline (St Bart's 1881 → last bow 1914) and the real-world publication timeline, with era and kind filters
- **Character dossiers** — eight principal figures, plus adversaries (Moriarty, Moran, Irene Adler)
- **Methods, 221B & Victorian London, myths vs canon** — including a scored myths-vs-canon verdict game
- **A scored deduction exercise** and a **seven-stage reading path** with a session-only progress tracker
- **Read-free links** — every novel, story, and reading-path stage links to a labeled public-domain text at Standard Ebooks and/or Project Gutenberg

All texts referenced are Doyle's public-domain canon. In-universe dates are traditional reconstructions — Doyle contradicted himself freely, and no chronology can be more exact than its author allowed. All six illustrations are original artworks created for the primer; no film or television imagery, no actor likenesses, and no material from any modern adaptation has been used.

## How to use it

Open the live site link above in any modern browser — desktop, tablet, or phone. No install, no account, no server. Browse the chapters, search the canon, try the deduction exercise, and follow the reading path at your own pace.

## Technical notes

- Single self-contained HTML file (`index.html`) — HTML, CSS, JavaScript, and illustrations in one file, no build step.
- The only external loads are Google Fonts (graceful fallback offline) and the labeled read-free links to Standard Ebooks / Project Gutenberg.
- Hosted as a static site on GitHub Pages. This is a second copy; the Muse original remains the source and its share link is unchanged.
